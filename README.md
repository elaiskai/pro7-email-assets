# PRO7 email assets

PRO7 naujienlaiškių HTML maketai ir jų vizualiniai failai.

## Kampanijos

- [`nl1-textile-impregnantas`](./nl1-textile-impregnantas/) — „Grįžo tekstilės impregnantas“ (rudens apsauga)
- [`nl2-20min-rudens-resetas`](./nl2-20min-rudens-resetas/) — „20 minučių rudens namų resetas“

Kampanijos aplanke yra paruoštas HTML, Omnisend personalizavimo žymos, šaltiniai, optimizuoti vaizdai ir desktop bei mobilioji peržiūros.

NL2 Omnisend Custom HTML bloke naudoti du failus: [omnisend.html](./nl2-20min-rudens-resetas/omnisend.html) turinį į HTML lauką ir [omnisend-styles.css](./nl2-20min-rudens-resetas/omnisend-styles.css) turinį į Styles lauką, be style žymų. Bloko išoriniai šoniniai tarpai 0 px, laiško plotis 600 px. HTML turi viešus HTTPS paveikslėlių adresus. NL2 index.html skirtas tik vietiniam redagavimui ir peržiūrai. [Įkėlimo instrukcija](./nl2-20min-rudens-resetas/CAMPAIGN.md) · [Patikros rezultatai](./nl2-20min-rudens-resetas/QA.md).
